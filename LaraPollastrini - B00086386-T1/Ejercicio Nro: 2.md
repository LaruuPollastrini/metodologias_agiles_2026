# Ejercicio Nro: 2

## Enunciado 
¿Qué es para vosotros el desarrollo de software?
* ¿Ejemplos de desarrollo de software en los que hayas participado? ¿Ejemplos que conozcas?

* ¿Cuál es el papel del desarrollador en el desarrollo de un proyecto software? 

* ¿Hay otros papeles importantes en el desarrollo, aparte del desarrollador? 

* ¿Cuándo se ha desarrollado un buen software? 

## Resolución
* Realizamos proyectos académicos para parciales/finales como por ejemplo el trabajo de ingeniería de software y trabajo de diploma en 3er año.
* El desarrollador en el desarrollo de un proyecto de software busca resolver un problema. Previamente comprende cuál es el problema, busca la mejor solución adaptándose a las necesidades del cliente, que pueden cambiar a lo largo del proceso.
* Si, hay otros papeles importantes en el desarrollo de software además del desarrollador como el cliente, el tester, el analista y quien se encarga de la arquitectura. 
* Se desarrolló un buen software cuando está bien hecho y hace lo que tiene que hacer.
