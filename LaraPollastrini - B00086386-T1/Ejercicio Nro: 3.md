# Ejercicio Nro: 3
## Enunciado 
Qué ventajas y desventajas tienen los diagramas UML ?

## Resolución
* Ventajas de los diagramas UML:
Permiten ver cómo será el sistema antes de programarlo. Ayudan a que todo el equipo entienda la estructura y sirven para detectar errores de diseño.
* Desventajas de los diagramas UML:
El software cambia todo el tiempo y mantener los planos actualizados cada vez que el código cambia es muy difícil y lleva mucho tiempo. Si el plano no se actualiza rápido, deja de servir y puede confundir al equipo.
